# Pixel Vault Ver. 1.0.1

เว็บคลัง Pixel FX แบบ static ใช้ Canvas แสดงพรีวิวและสร้าง PNG โปร่งใส หน้าเว็บสาธารณะแสดงเฉพาะ Asset ที่เผยแพร่จาก `assets/` และ `library.json` ตัวอย่างเอฟเฟกต์และ Character Walk เปิดใช้ได้ในโหมดจัดการบนเครื่อง

## ทดลองในเครื่อง

ดับเบิลคลิก `index.html` เพื่อดูพรีวิวและทดลองส่งออก ถ้าต้องการเพิ่ม แก้ไข ลบ หรือนำเข้าคลังบนเครื่อง ให้เปิด PowerShell ในโฟลเดอร์นี้แล้วรันคำสั่งด้านล่าง จากนั้นเปิด `http://localhost:8000/?manage=1` เพื่อเข้าโหมดจัดการ

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

- ค้นหาตามชื่อหรือเลือกหมวดหมู่ แล้วเลือกเอฟเฟกต์เพื่อเล่น หยุด หรือเลื่อนดูทีละเฟรม
- เอฟเฟกต์ตัวอย่างเปลี่ยน Palette และ New seed ได้ ทั้งตัวอย่างและ PNG ที่นำเข้าใช้ Mirror, FPS และ Loop ได้
- กด **Add sprite sheet** เพื่อเพิ่ม PNG กริดสม่ำเสมอ เรียงเฟรมจากซ้ายไปขวาแล้วลงแถวถัดไป โดยไม่มีช่องว่างระหว่างเฟรม ใส่ขนาดเฟรมเป็นพิกเซลและจำนวนเฟรมที่ใช้จริง ขนาดเฟรมสูงสุด 512 × 512 และสูงสุด 120 เฟรม
- เช็กขนาดและเส้นกริดในพรีวิวก่อนบันทึก เปิด **แบ่งคลิปตามแถว** เพื่อสร้างหลายคลิปจาก PNG เดียว แผ่น 4 แถวจะได้ชื่อเริ่มต้น Walk Down, Walk Left, Walk Right, Walk Up เปลี่ยนชื่อ จำนวนเฟรม FPS และ Pivot ได้ทีละแถว เว้นชื่อแถวว่างเพื่อข้ามแถวนั้น
- ระบุ **กลุ่มตัวละคร** เดียวกันสำหรับคลิปที่ต้องการส่งออกด้วยกัน เช่น คลิปเดินจากแผ่นแรกกับ Idle จากอีกแผ่น หากแบ่งคลิปตามแถวและเว้นกลุ่มว่าง เว็บใช้ชื่อที่กรอกตอนนำเข้าเป็นชื่อกลุ่ม
- กด **แก้ไข Asset** เพื่อแก้ชื่อ หมวดหมู่ หรือปรับช่วงเฟรมและเปลี่ยน PNG สำหรับคลิปที่นำเข้า การเปลี่ยน PNG มีผลกับคลิปที่เลือก
- คลังที่เพิ่มเองเก็บใน IndexedDB ตามเบราว์เซอร์ โปรไฟล์ และที่อยู่เว็บ กด **Export library** เพื่อสำรองเป็น `library.json` ซึ่งรวมข้อมูล PNG และใช้ **Import library** เพื่อกู้คืนหรือย้ายเครื่อง
- เลือก Asset หรือตัวอย่างที่ติดมากับเว็บ แล้วกด **ลบ Asset** ใต้พรีวิว รายการจะหายจากคลังในเบราว์เซอร์นี้และจะไม่แสดงในคลังที่ส่งออกครั้งถัดไป หากเผยแพร่ผ่าน GitHub Pages ให้กด **Export library** แล้วนำ `library.json` ไปแทนไฟล์ใน repository เพื่อให้ผู้เข้าชมเห็นคลังที่อัปเดต
- กด **เลิกทำการลบ** เพื่อคืนรายการที่ลบล่าสุดก่อนรีเฟรช หรือ **คืนค่าตัวอย่าง** เพื่อแสดงตัวอย่างที่ติดมากับเว็บทั้งหมดอีกครั้ง

## ส่งเข้า Unity

### Character Walk

- เลือก **Characters → Character Walk** ใน Library แล้วเลือกทิศทางเพื่อดูพรีวิววนทีละ 4 เฟรมที่ 8 FPS
- ปรับ **Shirt color**, **Hair color** และ **Seed** แล้วกด **Save to Library** เพื่อเก็บชุดที่ปรับไว้ในเบราว์เซอร์ ใช้ **Export library** เพื่อสำรองชุดที่บันทึก
- เปิด **Details & Export** เพื่อดูกริดและดาวน์โหลด PNG โปร่งใสขนาด 128 × 128 px กับ JSON ที่ระบุตำแหน่งแต่ละเฟรมด้วยดัชนีเริ่มจาก 0
- กด **Export Character ZIP** เพื่อส่งออกคลิปเดิน 4 ทิศเป็น PNG และข้อมูลเฟรมสำหรับตัวนำเข้า Unity ด้านล่าง
- ใน Unity ใช้ PNG แบบ Multiple และตัดด้วย Grid by Cell Size ขนาด 32 × 32 px ใช้เฟรมซ้ายไปขวาของแต่ละแถวสร้างคลิปเดิน 4 คลิปตามลำดับ Down, Left, Right, Up ตั้งแต่ละคลิปเป็น 8 FPS และเปิด Loop

### เอฟเฟกต์และ Sprite Sheet ที่นำเข้า

1. ติดตั้งแพ็กเกจ **2D Sprite** (`com.unity.2d.sprite`) ใน Package Manager หากยังไม่มี ตัวนำเข้าใช้ Sprite Editor Data Provider ของ Unity 2022.3 ขึ้นไป
2. คัดลอก `unity/PixelVaultImporter.cs` เข้า `Assets/Editor/` ในโปรเจกต์ Unity ทำครั้งเดียว
3. กด **Export Unity ZIP** เพื่อส่งออกคลิปที่เลือก หรือ **Export Character ZIP** เพื่อส่งออกทุกคลิปในกลุ่มพร้อมกัน การส่งออกกลุ่มใช้ FPS, Loop และ Pivot ที่บันทึกในแต่ละคลิป และใช้ PPU เดียวกันทั้งกลุ่ม แตก ZIP แล้วนำ PNG กับ `*.pixelvault.json` ไปไว้โฟลเดอร์เดียวกันภายใต้ `Assets/`
4. เลือกไฟล์ `*.pixelvault.json` หนึ่งไฟล์หรือหลายไฟล์ในหน้าต่าง Project แล้วใช้เมนู **Assets → Pixel Vault → Import Sprite Sheet and Animation** สคริปต์จะตั้ง Point filter, ใช้ Pivot ตามที่เลือก และสร้างไฟล์ `.anim` สำหรับ SpriteRenderer ในโฟลเดอร์เดียวกัน Pivot ด้านล่างยึดกับขอบล่างของช่องเฟรม จึงควรจัดเท้าตัวละครให้อยู่ระดับเดียวกันก่อนนำเข้า
5. ใช้คลิปกับ Animator บน GameObject ที่มี SpriteRenderer หากต้องการใช้เฉพาะภาพ สามารถนำ PNG ไปตั้ง Sprite Mode เป็น Multiple และตัดด้วย Grid by Cell Size ตาม width/height ใน JSON ได้

## เผยแพร่ผ่าน GitHub Pages

### ตั้งค่าครั้งเดียว

1. วางไฟล์จาก ZIP ที่ root ของ repository เดิม โดยเก็บ `library.json` เดิมไว้ถ้ามีคลังที่เผยแพร่อยู่แล้ว และคัดลอกโฟลเดอร์ซ่อน `.github` มาด้วย ต้องเห็นไฟล์ `.github/workflows/pages.yml` ใน repo
2. ใน **Settings → Pages → Build and deployment → Source** เลือก **GitHub Actions**
3. Commit และ push ขึ้น `main` หรือเปิด **Actions → Publish Pixel Vault → Run workflow** ที่ branch `main` ถ้าใช้ branch อื่น ให้แก้ชื่อ branch ใน workflow ทั้งเงื่อนไข push และ build
4. รอให้ workflow ผ่านแล้วเปิดลิงก์เดิมจากหน้า Pages เว็บที่เผยแพร่จะแสดงพรีวิว ปุ่มดาวน์โหลด และตัวเลือกส่งออก โดยซ่อนปุ่มจัดการคลัง

ถ้า Asset เดิมอยู่เฉพาะในเบราว์เซอร์ ให้ **Export library** จากเว็บเดิมก่อนสลับโหมด แล้ว commit ไฟล์นั้นเป็น `library.json` ครั้งเดียวเพื่อย้ายเข้าคลังสาธารณะ ให้ใส่เฉพาะรูปที่ตั้งใจเผยแพร่

### เพิ่มรูปใหม่

1. เข้าโฟลเดอร์ `assets/` ใน GitHub แล้วเลือก **Add file → Upload files**
2. ลาก PNG ลงหน้า GitHub แล้วกด **Commit changes** เมื่องาน **Publish Pixel Vault** ผ่าน รูปจะปรากฏในเว็บอัตโนมัติ
3. เมื่อต้องการเอารูปออก ให้ลบ PNG และ JSON คู่กันใน repo แล้ว commit อีกครั้ง รายการที่เคยเผยแพร่ผ่าน `library.json` เดิมให้แก้ที่ไฟล์นั้น

แผ่น `256 × 256 px` ใช้เฟรม `64 × 64 px` แบ่งเดิน 4 ทิศจากบนลงล่างเป็น Down, Left, Right, Up ที่ **8 FPS / 64 PPU** โดยอัปเพียง PNG ไฟล์เดียว หากใช้ขนาดกริดหรือค่าต่างออกไป ให้ใส่ JSON ชื่อเดียวกันกับ PNG ตาม [ตัวอย่างในโฟลเดอร์ assets](assets/README.md) ปรับ FPS และ PPU ก่อนส่งออกคลิปเดี่ยวได้จากหน้าพรีวิว

หน้าเว็บปกติซ่อนปุ่ม Import library, Export library และ Add sprite sheet ใช้ `?manage=1` บน localhost จากโฟลเดอร์ต้นฉบับเมื่อต้องการจัดการคลังในเครื่อง ถ้าต้องการทดสอบเว็บแบบสาธารณะจาก PNG ใน `assets/` ให้สร้างเว็บทดสอบในโฟลเดอร์ว่างก่อน แล้วเปิด `http://localhost:8000`

```powershell
python tools/build_pages.py --output _site
python -m http.server 8000 --bind 127.0.0.1 --directory _site
```
