# รูปสำหรับคลังสาธารณะ

อัปโหลด PNG ลงโฟลเดอร์นี้แล้ว commit ไปที่ `main` รูป `256 × 256` จะใช้เฟรม `64 × 64` และแบ่งตามแถวเป็น Down, Left, Right, Up ที่ 8 FPS / 64 PPU รูปขนาดอื่นจะแสดงเป็นภาพเฟรมเดียว หากกว้างและสูงไม่เกิน 512 px

ถ้ารูปใช้กริดหรือ FPS/PPU ต่างจากค่าเริ่มต้น ให้เพิ่มไฟล์ JSON ชื่อเดียวกับ PNG เช่น `slime.png` คู่กับ `slime.json`

```json
{
  "name": "Slime",
  "category": "Monsters",
  "layout": "sheet",
  "frameWidth": 32,
  "frameHeight": 32,
  "frames": 6,
  "fps": 10,
  "ppu": 32,
  "loop": true,
  "pivot": "feet"
}
```

- `layout: "walk4"` แบ่ง PNG เป็น 4 แถว แถวละทิศ กำหนดขนาดเฟรมเองได้
- `layout: "sheet"` เล่นเฟรมจากซ้ายไปขวาแล้วลงแถวถัดไป ใช้ `frameWidth` และ `frameHeight` ระบุขนาดช่อง เว้น `frames` เพื่อใช้ทุกช่อง
- `layout: "single"` แสดงภาพทั้งภาพเป็นเฟรมเดียว ใช้ตัวเลือกนี้ถ้ารูป 256 × 256 ไม่ใช่แผ่นเดิน 4 ทิศ
- `group` เป็นชื่อกลุ่มสำหรับ **Export Character ZIP** ตั้งชื่อเดียวกันเพื่อรวมคลิปจาก PNG คนละไฟล์ เช่น Walk และ Idle โดยใช้ PPU เดียวกันทั้งกลุ่มตอนส่งออก
- `pivot: "feet"` ใช้จุดกึ่งกลางขอบล่างของเฟรม ส่วน `"center"` ใช้จุดกึ่งกลาง
